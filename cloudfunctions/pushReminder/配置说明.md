# 云函数 pushReminder 部署说明

## 功能
定时检查订阅的物品是否上架，上架时通过微信订阅消息推送到用户的服务通知。

## 部署步骤

### 1. 开通云开发
微信开发者工具 → 顶部「云开发」→ 开通（免费额度：2GB 存储 / 5GB 流量 / 4 万次调用每月）

### 2. 部署云函数
1. 开发者工具左侧资源管理器 → `cloudfunctions/pushReminder` 文件夹右键
2. 「创建并部署：云端安装依赖」

### 3. 创建定时触发器
云开发控制台 → 云函数 → pushReminder → 触发器 → 新建触发器：
- 触发方式：定时触发器
- Cron 表达式：`* * * * *`（每分钟）

### 4. 创建数据库集合
云开发控制台 → 数据库 → 新建集合：
- 集合名：`subscriptions`
- 权限：所有用户可读，仅创建者可写

### 5. 小程序端开启云能力
`app.js` 的 `App({})` 最前面加：
```js
wx.cloud.init({ env: '你的环境ID', traceUser: true });
```

### 6. 填模板 ID
`pages/index/index.js` 顶部 `SUBSCRIBE_TMPL_ID` 填入真实模板 ID

## 订阅数据上报（前端已预留）
用户确认订阅时，需要把订阅信息写入云数据库（在 onConfirmSubscribe 里加）：
```js
wx.cloud.callFunction({
  name: 'pushReminder',
  data: { action: 'sub', items: arr, tmplId: SUBSCRIBE_TMPL_ID }
});
```
（云函数里需加 action==='sub' 分支写入 subscriptions 集合）

## 注意
- 一次性订阅消息：用户每次授权 = 可推送 1 条
- 用户勾选"总是保持以上选择"可免重复弹窗
- 免费额度 4 万次调用/月，每分钟 1 次 = 43200 次（刚好够）
